## Featured Projects

### [Climbing Regulations RAG](https://github.com/pdegner/climbing-regulations-rag)

A citation-grounded question-answering system for federal climbing regulations from the Forest Service, BLM, National Park Service, and Fish & Wildlife Service.

Built with Python, Amazon Bedrock, PostgreSQL, pgvector, FastAPI, Lambda, RDS, Docker, and AWS CDK. It combines semantic and keyword retrieval with AI reranking, evaluates multiple retrieval strategies, and uses constrained citation handling to prevent the model from inventing sources.

### [notes-mcp](https://github.com/pdegner/notes-mcp)

A Model Context Protocol server that gives Claude Code and Claude Desktop access to local Markdown notes.

It supports tools, resources, and prompts for creating, searching, retrieving, deleting, and summarizing notes while keeping the underlying data local, portable, and human-readable.

### [BERT Sentiment Analysis](https://github.com/pdegner/MP_Sentiment_Analysis)

A graduate-school natural language processing project from the era when BERT was the hot new language model, code was still written by hand, and if you had a question your best option was to descend into the bowels of StackOverflow or worse: read the documentation. 

The project may now be a relic of days past, but building it gave me a foundational understanding of NLP, model training, evaluation, and the mechanics behind the AI systems I work with today.
